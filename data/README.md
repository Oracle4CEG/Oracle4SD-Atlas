# Data

Three stages preserve evidence: data_source stores frozen inputs, queried_data archives acquired inputs, processed_data contains derived tables. These bundled files describe one real UMA case. Full-data availability and inventory are in ../docs/FULL_DATA.md and ../metadata/full_data_inventory.csv.
