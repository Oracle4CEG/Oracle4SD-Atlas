# Metadata

release.json is the identity authority. source_register.csv and file_manifest.csv describe permitted case files. data_dictionary.csv defines all 85 case fields; table_dictionary.json documents child units. acquisition_profiles.json and contracts.csv record chain-specific acquisition. production_code_imports.csv binds imported source bytes. full_data_inventory.csv describes 71 separately scoped candidate files. issue_log.csv, validation_plan.csv, process_trace.csv, claim_evidence.csv, result_index.json and reproduction_record.csv support review. Historical source manifests and dictionaries are retained as evidence and are not silently repaired.
