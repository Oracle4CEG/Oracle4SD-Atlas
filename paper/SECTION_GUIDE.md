# Data Descriptor alignment checklist

- Background & Summary: describe the dataset's scientific value and heterogeneous observation units; avoid predictive-performance claims.
- Methods: cite Luo et al. §3.2 for the collection comparison and explain protocol-native adaptations, exact cutoffs, versions, provenance and failure handling.
- Data Records: distinguish one runnable case, published review/demo subsets and the unpublished full candidate; report filenames, hashes, units, schemas and archive status.
- Technical Validation: report scoped raw/QC/schema checks and denominators, known failures, missingness and actual independent reproduction status.
- Usage Notes: explain returned principal versus gain, accrued versus applied changes, protocol decisions versus external truth, censored outcomes and resource limits.
- Data / Code Availability: use actual immutable links and reviewed commits; no invented DOI, Overleaf link or full archive.
