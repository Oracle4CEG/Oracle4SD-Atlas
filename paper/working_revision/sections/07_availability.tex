\section{Data and code availability}

The earlier release is available through the project's Hugging Face repository.\footnote{Data and documentation: \url{https://huggingface.co/datasets/Oracle4CEG/OracleEconLab-Oracle-Incentives-v1}.} It contains native and derived tables, source registers and validation materials. New daily measurements, the revised UMA task and evidence ledgers accompany this working paper but have no separate public deposit version. Their catalogue records file identities, variable definitions and links to the earlier release.

The public processing repository provides the earlier reconstruction and case-replay code.\footnote{Processing and case replay: \url{https://github.com/Oracle4CEG/Oracle4SD-Atlas}.} The revision package includes the additional processing scripts, figure sources and an executed tutorial with bounded examples for all eight branches. Input versions and execution records distinguish archived reconstruction from fresh public-interface acquisition. Appendix~\ref{app:reproduction} describes the reproducibility boundaries.
